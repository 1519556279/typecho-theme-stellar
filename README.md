# Stellar（星辰）· Typecho 主题

> 现代、简洁、功能全面的 Typecho 博客主题。毛玻璃、渐变星辰配色、克制动效，开箱即用。

![screenshot](Stellar/screenshot.png)

## ✨ 特性

**视觉**
- 毛玻璃吸顶导航、渐变强调色、圆角卡片布局
- **6 套配色模板**（后台一键切换：靛紫/天蓝/翡翠绿/玫瑰粉/琥珀橙/紫罗兰，亮暗模式自动适配）
- 暗色模式：右上角切换，**View Transition 圆形扩散动画**，自动记忆偏好并跟随系统
- 完全响应式：桌面双栏 / 平板 / 手机单栏，刘海屏安全区适配

**评论**
- **QQ 邮箱自动显示 QQ 头像**；其他邮箱显示 cravatar 头像
- 无头像时自动使用**本地渐变色字母头像**（永不破图、不依赖外网）
- 嵌套回复、博主显示站名、等待审核标记

**功能**
- 文章目录：**右侧悬浮跟随高亮**（桌面端）
- 友情链接：后台配置 + 侧边栏 + 独立友链页模板
- 代码块：内置轻量高亮引擎 + 一键复制按钮
- 图片懒加载 + 灯箱查看、搜索（Ctrl/Cmd+K）、阅读进度、相关阅读、上下篇

**动效（均遵循系统「减少动态」设置）**
- 标题逐字浮现、返回顶部**进度环**、双击空白爆星星、选中文字复制气泡、阅读胶囊（读完变 ✓）、404 漂浮星星

## 📦 安装

1. 下载本仓库，将 `Stellar` 文件夹放入 Typecho 的 `usr/themes/` 目录
2. 后台 **设置 → 外观** 启用 Stellar
3. **设置 → 设置外观** 配置主题（见下）

## ⚙️ 后台配置

| 配置项 | 说明 |
| --- | --- |
| 主题配色 | 6 套强调色，亮/暗自动适配 |
| 博主头像 | 开关（默认隐藏，控制首页/侧边栏头像） |
| 站点简介 | 显示在首页 Hero 与侧边栏 |
| 友情链接 | 每行一个：`名称\|链接\|简介`，支持 `#` 注释行 |

**友链页**：后台「管理 → 独立页面 → 新建」，模板选择「友链」即可生成卡片式友链页。

## 📁 目录结构

```
Stellar/
├── index.php / archive.php / post.php / page.php / 404.php
├── header.php / footer.php / sidebar.php / comments.php
├── functions.php      （后台设置、头像、友链、相关文章）
├── page-friends.php   （友链页模板）
├── style.css          （全部样式）
└── assets/js/main.js  （全部交互）
```

## 🔧 兼容性

- Typecho **1.2+ / 1.3**（建议 1.3）
- PHP 7.4+（建议 8.x）
- 现代浏览器：Chrome / Edge / Firefox / Safari 较新版本
